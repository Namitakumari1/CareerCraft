# CareerCraft

CareerCraft is a full-stack MERN application for
building professional resumes and tracking job applications.

## Features

- User registration and login
- JWT authentication
- Password hashing with bcrypt
- Authorization
- Resume builder
- Resume templates
- Job application tracking
- Dashboard analytics
- PDF resume export

## Tech Stack

### Frontend
- React
- React Router
- CSS

### Backend
- Node.js
- Express
- MongoDB
- Mongoose

### Authentication
- JWT
- bcrypt
